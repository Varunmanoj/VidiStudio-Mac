Write and edit audio descriptions

Describe useful visual information clearly and briefly. Prioritize what a listener needs to understand the story, demonstration, or on-screen instruction. Avoid repeating dialogue that already communicates the same point.

Add a segment

  1. Seek near the intended description and choose Descriptions.
  2. Choose Add Segment, or press Command-Shift-N (Mac) / Ctrl-Shift-N (Windows).
  3. Set Start time and End time. The hours, minutes, seconds, and milliseconds controls support Up/Down Arrow adjustments.
  4. Enter the description. Keep it short enough to be spoken in the available time.
  5. Resolve any timing warnings, then choose Save Segment. Cancel discards the draft.

The segment editor includes an Origin picker for the description's provenance. Choose AI-generated, AI-generated · modified, Imported, Imported · modified, Manually added, or Origin unknown. A manual choice is saved with the segment and is not inferred later from its ID or narration file. Saving a new description without a choice uses Manually added.

Correct text and timing

Descriptions opens in view mode. Choose Edit to show selection checkboxes and the pencil control beside every segment. Choose a pencil to edit one segment. The editor displays its duration and identifies overlaps with transcript speech or other descriptions. Save Segment is disabled for empty text, an invalid range, a range outside the video, or an overlap. End must be later than start. Change the times or text to resolve the warning.

To edit several descriptions, select their checkboxes and choose Edit Selected. Choose each selected row in the dialog, correct its text and timing, then choose Save All. Select All and Deselect All are available from Selection. Read Frame Text in the single-segment sheet can replace the draft with text detected at the start time. Review the replacement before saving. Generated descriptions and frame-text results can need corrections to names, spelling, or context.

Delete selected descriptions

In edit mode, select one or more descriptions and choose Delete Selected. The confirmation reports how many segments will be permanently removed. Confirming deletes each selected description's text and timing and also deletes its corresponding generated narration file; narration for descriptions that were not selected is kept. Cancel leaves every segment and audio file unchanged.

Use segment actions

In Edit mode, the three-dot More Options button opens a menu with icons for Rewrite to Fit, Synthesize This Segment, Delete Segment Audio, and Delete Segment. The text labels remain visible alongside each icon.

Import Narration Audio… replaces the selected segment's narration without using the selected voice or an API key. Choose a WAV, MP3, M4A, AAC, or FLAC file. The file is accepted when it fits inside the segment's start and end time; shorter audio is allowed, with the rest of the segment left silent. Audio longer than the segment is rejected with both durations and the segment range, and the existing narration is untouched. If the segment already has narration, VidiStudio asks before replacing it, then replaces the old file only after the new one passes validation. Imported narration is labelled Imported audio with its source file name in narration reports, and the selected voice applies only to future generated narration. Import Narration Audio is available in edit mode and in the row's contextual menu.

The contextual menu offers Rewrite to Fit, Synthesize This Segment, Import Narration Audio, narration preview controls, and Delete Segment. Delete Segment asks for confirmation before permanently removing the segment's text, timing, and narration. Choose Cancel to keep it unchanged. Rewrite to Fit uses the configured Gemini rewrite model to shorten the description; review its wording afterward. Synthesize This Segment generates saved speech for only that description. Each description row has Play Narration and Stop Narration controls. Play changes to Pause while its audio is playing and to Resume while paused. Stop returns the preview to the beginning. Play and Pause are disabled when synchronized audio is unavailable, while Stop is enabled only for the active or paused segment.

Track changes

Origin labels distinguish AI-generated, AI-generated · modified, Imported, Imported · modified, Manually added, and Origin unknown. Imported descriptions start as Imported; editing their text or timing changes the label to Imported · modified unless you choose another label explicitly. Older segments without recorded provenance remain Origin unknown rather than being inferred from an ID or a narration file. AD Overview counts every one of the six labels. Audio status distinguishes ready narration, narration that needs regeneration after a text edit, and missing audio. A different currently selected voice alone does not invalidate a matching saved file.

Regenerate Audio Descriptions regenerates every Audio Description segment and its rows in AD Transcript. Immediately before generating the new descriptions, VidiStudio deletes all narration audio associated with the old segments. Existing exports remain as previously created files, but narration must be synthesized again before creating an updated described export. If you only want to add or improve descriptions for particular sections, choose Cancel in the regeneration warning. Open Add Segment in Descriptions, set the section's time range, and choose Re-Analyze This Segment. This targeted option keeps unrelated descriptions instead of regenerating the Audio Description for the entire video.

Delete Segment Audio in a description's action menu asks for confirmation, then removes only that segment's generated narration and keeps its text and timing. Preview Narration becomes unavailable until audio is synthesized again. The inspector's narration trash action asks for confirmation before deleting narration for every description without deleting any segments. The same bulk action is available from Project > Narration > Delete All Narration Audio, with Command-Option-Delete (Mac) / Ctrl-Alt-Backspace (Windows).

Undo Segment Edit and Redo restore AD edit history. These commands are separate from standard text undo inside the editor. Deleting generated content or clearing edit history is not the same as an ordinary reversible segment edit.

Resolve description timing

VidiStudio checks every description against the transcript and the other descriptions. A description that overlaps dialogue or another description keeps its text and times; it is never moved or deleted automatically. The affected row shows an Overlap badge whose accessible label reads “Needs retiming.” A persistent banner at the top of the editor reads Description timing needs attention and reports how many segments need retiming, with buttons to review Descriptions and, after an import, the Import Report.

AD Overview reports the same number under Description timing. Described video, described audio, narration-only audio, and audio combining remain unavailable until every flagged description is retimed; text exports remain available. Edit the times in the affected rows, or correct imported timing, then recheck AD Overview or the banner.

Re-analyze a section

Set a range in Add or Edit Audio Description. Use the Description text box only when you want to write and save a description manually. To guide Gemini, enter optional guidance in the separate Hint for Gemini text box, then choose Re-Analyze This Segment. Gemini uses the video, summary, transcript, existing descriptions, and your hint to add detail and reconcile nearby text and timing around dialogue. The hint guides what Gemini examines and is not automatically inserted as description text. Unrelated descriptions stay unchanged. The result is saved automatically only after timing validation; use Undo Segment Edit to restore it. Changed segments need new narration. A transcript and summary must exist first. Writing a description manually also requires a transcript so overlap validation can run. Project > Segments > Re-Analyze a Video Section opens this dialog with Command-Option-R (Mac) / Ctrl-Alt-R (Windows).
