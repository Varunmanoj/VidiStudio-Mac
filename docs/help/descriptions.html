Write and edit audio descriptions

Describe useful visual information clearly and briefly. Prioritize what a listener needs to understand the story, demonstration, or on-screen instruction. Avoid repeating dialogue that already communicates the same point.

Total AD characters

Total AD characters appears in the Audio Description inspector section on Descriptions and AD Overview, and in the main AD Overview statistics. It totals the text across every AD segment in the current viewing language and selected description result, including spaces, line breaks and punctuation. Combined characters and emoji count as displayed characters. Segment numbers, timestamps, transcript text and other saved versions or languages are excluded; filtering or selecting rows does not narrow the total. Saving edits, adding or deleting segments, or switching language or saved result refreshes the count. No descriptions shows 0.

For dialogue-free films, silent videos, and music-only videos, a completed empty transcript is valid. Built-in generation uses the visuals directly. Instrumental music can accompany spaced descriptions; preserve speech, sung lyrics, important sounds, and musical moments. Review generated timing against the actual soundtrack. See dialogue-free and music-video analysis.

Add a segment

  1. Seek near the intended description and choose Descriptions.
  2. Choose Add Segment, or press Command-Shift-N (Mac) / Ctrl-Shift-N (Windows).
  3. Set Start time and End time. The hours, minutes, seconds, and milliseconds controls support Up/Down Arrow adjustments.
  4. Enter the description. Keep it short enough to be spoken in the available time.
  5. Resolve any timing warnings, then choose Save Segment. Cancel discards the draft.

The segment editor includes an Origin picker for the description's provenance. Choose AI-generated, AI-generated · modified, Imported, Imported · modified, Manually added, or Origin unknown. A manual choice is saved with the segment and is not inferred later from its ID or narration file. Saving a new description without a choice uses Manually added.

Correct text and timing

Descriptions opens in view mode. Right-click a segment and choose Edit Segment to change its start time, end time, and text without turning on Edit mode. For multiple changes, choose Edit to show selection checkboxes and per-row pencil controls. The editor displays its duration and identifies overlaps with transcript speech or other descriptions. Save Segment is disabled for empty text, an invalid range, a range outside the video, or an overlap. End must be later than start. Change the times or text to resolve the warning.

To edit several descriptions, select their checkboxes and choose Edit Selected. Choose each selected row in the dialog, correct its text and timing, then choose Save All. Select All and Deselect All are available from Selection. Read Frame Text in the single-segment sheet can replace the draft with text detected at the start time. Review the replacement before saving. Generated descriptions and frame-text results can need corrections to names, spelling, or context.

Delete selected descriptions

In edit mode, select one or more descriptions and choose Delete Selected. The confirmation reports how many segments will be permanently removed. Confirming deletes each selected description's text and timing and removes its narration from the selected result; files referenced by other results, drafts, or histories are kept. Cancel leaves every segment and audio file unchanged.

Deleting transcript or Audio Description rows removes only those annotations and the selected descriptions’ narration; it does not cut video or original audio, shorten the video duration, or shift any remaining timestamps. You can remove a song’s transcript and descriptions from the middle of a video and leave a gap. Existing timing conflicts in unselected rows do not block deletion. New or edited rows still need valid times inside the video and must not overlap other rows of the same type; descriptions must also avoid transcript dialogue. Existing description timing warnings are recalculated after deletion.

Use segment actions

In Edit mode, the three-dot More Options button opens a menu with icons for Rewrite to Fit, Synthesize This Segment, Delete Segment Audio, and Delete Segment. The text labels remain visible alongside each icon.

Import Narration Audio… replaces the selected segment's narration without using the selected voice or an API key. Choose a WAV, MP3, M4A, AAC, or FLAC file. The file is accepted when it fits inside the segment's start and end time; shorter audio is allowed, with the rest of the segment left silent. Audio longer than the segment is rejected with both durations and the segment range, and the existing narration is untouched. If the segment already has narration, VidiStudio asks before replacing it, then replaces the old file only after the new one passes validation. Imported narration is labelled Imported audio with its source file name in narration reports, and the selected voice applies only to future generated narration. Import Narration Audio is available in edit mode and in the row's contextual menu.

The contextual menu offers Rewrite to Fit, Synthesize This Segment, Import Narration Audio, narration preview controls, and Delete Segment. Delete Segment asks for confirmation before permanently removing the segment's text, timing, and narration. Choose Cancel to keep it unchanged. Rewrite to Fit uses the configured Gemini rewrite model to shorten the description; review its wording afterward. Synthesize This Segment generates saved speech for only that description. Each description row has Play Narration and Stop Narration controls. Play changes to Pause while its audio is playing and to Resume while paused. Stop returns the preview to the beginning. Play and Pause are disabled when synchronized audio is unavailable, while Stop is enabled only for the active or paused segment.

Track changes

Origin labels distinguish AI-generated, AI-generated · modified, Imported, Imported · modified, Manually added, and Origin unknown. Imported descriptions start as Imported; editing their text or timing changes the label to Imported · modified unless you choose another label explicitly. Older segments without recorded provenance remain Origin unknown rather than being inferred from an ID or a narration file. AD Overview counts every one of the six labels. Audio status distinguishes ready narration, narration that needs regeneration after a text edit, and missing audio. A different currently selected voice alone does not invalidate a matching saved file.

Successful generation, regeneration, segment reanalysis, and Rewrite to Fit automatically save and select the new result for its language in Transcript, Summary, or Descriptions. Earlier versions, narration, exports, and edit history remain available. If the result matches View Project Language, it appears immediately; a result generated in another language becomes that language’s selected version without changing the language you are viewing or independent generation targets. Switch View Project Language to inspect it. Auto remains a separate category. Analyze Video and Regenerate All select each successfully completed section in the same way. Use the section’s Saved Result picker to compare or return to an earlier version. Failed or cancelled work keeps the previous selection and retains available checkpoints as review drafts, including after reopening. For pending imports and recoverable drafts, Review… offers Keep Both, Replace Selected, or Discard New; Keep Both is the default and Review Later retains the draft. A completed narration run also selects its new saved version, including successful audio when another segment fails. Failed segments retain their issues; interrupted narration remains a recoverable draft.

Delete Segment Audio in a description's action menu asks for confirmation, then removes only that segment's generated narration and keeps its text and timing. Preview Narration becomes unavailable until audio is synthesized again. The inspector's narration trash action asks for confirmation before deleting narration for every description without deleting any segments. The same bulk action is available from Project > Narration > Delete All Narration Audio, with Command-Option-Delete (Mac) / Ctrl-Alt-Backspace (Windows).

Undo Segment Edit and Redo restore AD edit history. These commands are separate from standard text undo inside the editor. Deleting generated content or clearing edit history is not the same as an ordinary reversible segment edit.

Resolve description timing

VidiStudio checks every description against the transcript and the other descriptions. A description that overlaps dialogue or another description keeps its text and times; it is never moved or deleted automatically. The affected row shows an Overlap badge whose accessible label reads “Needs retiming.” A persistent banner at the top of the editor reads Description timing needs attention and reports how many segments need retiming, with buttons to review Descriptions and, after an import, the Import Report.

AD Overview reports the same number under Description timing. Described video, described audio, narration-only audio, and audio combining remain unavailable until every flagged description is retimed; text exports remain available. Edit the times in the affected rows, or correct imported timing, then recheck AD Overview or the banner.

Re-analyze a section

Set a range in Add or Edit Audio Description. Use the Description text box only when you want to write and save a description manually. To guide Gemini, enter optional guidance in the separate Hint for Gemini text box, then choose Re-Analyze This Segment. Gemini uses the video, summary, transcript, existing descriptions, and your hint to add detail and reconcile nearby text and timing around dialogue. The hint guides what Gemini examines and is not automatically inserted as description text. Unrelated descriptions stay unchanged. The result is saved automatically only after timing validation; use Undo Segment Edit to restore it. Changed segments need new narration. A transcript and summary must exist first. Writing a description manually also requires a transcript so overlap validation can run. Project > Segments > Re-Analyze a Video Section opens this dialog with Command-Option-R (Mac) / Ctrl-Alt-R (Windows).

If a section has no selected source transcript or summary in its current language, choose an existing saved source when prompted by Choose source transcript or Choose source summary. Sources can come from another language. VidiStudio generates only the requested section in its target language and records those source choices; it does not regenerate the source sections.

Choose a target language for each section

Edit mode: Select the tab you want to work on, then use its toolbar Edit/Done button or the matching command in the inspector’s Language and Saved Results controls. The inspector stays visible and switches to Done Editing while editing. On Descriptions, choose Edit > Edit Audio Description Segments, directly after Copy to…, or Edit > Done Editing Segments to finish. These controls and Project > Segments share the same editing state. Use Command-Option-E (Mac) / Ctrl-Alt-E (Windows) to toggle the active editable section. Language and Saved Results shows transcript controls on Transcript, summary controls on Summary, and description/narration controls on Descriptions. AD Overview shows description/narration results; AD Transcript shows its transcript and description sources. Only View Project Language is a shared project setting. View Project Language and saved-result selection are available in view mode. Changing section generation targets, using Keep All Sections in Sync, and assigning a language label require Edit mode. Save or cancel pending summary edits before changing languages or saved results. Choosing a target does not translate existing content; generate a result to create text in that language.

Transcript Generation Language, Summary Generation Language, and Descriptions and Narration Generation Language each have their own target-language picker in Language and Saved Results. Choose a specific language or Auto independently for each section. For example, a Hindi video can have an English transcript, a Hindi summary, and Marathi descriptions. Follow Project Language is optional for each section; those generation targets follow View Project Language for future requests, while explicit targets stay independent. Viewing always uses View Project Language across sections. Keep All Sections in Sync returns every section to Follow Project Language without deleting saved results. AD Transcript uses the chosen transcript and description results; narration stays attached to its description version.

AD audio readiness by language

The inspector shows a green check when every AD segment in the selected description result has usable text and narration audio, and a red cross if any segment is incomplete. Missing, empty or unavailable recordings, narration that needs regeneration, empty description text and invalid segment timing keep the status red. No AD segments also shows red. A count such as Hindi · 17/18 AD audio identifies the language and complete segments.

Descriptions and AD Overview show the active language status in the Audio Description inspector section. Beside Export, the icon reports the current language; the rows below list each language’s own selected description result. A complete English result does not mark incomplete Hindi narration ready, and an unselected complete version does not hide issues in the selected one. Screen-reader names and tooltips include the language and counts. These are status indicators, not buttons. Export remains available for standalone text and original-audio choices; described audio/video still use their existing narration requirements. The export dialog is unchanged.
