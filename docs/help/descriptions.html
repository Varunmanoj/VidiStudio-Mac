Write and edit audio descriptions

Describe useful visual information clearly and briefly. Prioritize what a listener needs to understand the story, demonstration, or on-screen instruction. Avoid repeating dialogue that already communicates the same point.

Add a segment

  1. Seek near the intended description and choose Descriptions.
  2. Choose Add Segment, or press Command-Shift-N.
  3. Set Start time and End time. The hours, minutes, seconds, and milliseconds controls support Up/Down Arrow adjustments.
  4. Enter the description. Keep it short enough to be spoken in the available time.
  5. Resolve any timing warnings, then choose Save Segment. Cancel discards the draft.

Correct text and timing

Choose Edit beside a segment. The editor displays its duration and identifies overlaps with transcript speech or other descriptions. Save Segment is disabled for empty text, an invalid range, a range outside the video, or an overlap. End must be later than start. Change the times or text to resolve the warning.

Read Frame Text in this sheet can replace the draft with text detected at the start time. Review the replacement before saving. Generated descriptions and frame-text results can need corrections to names, spelling, or context.

Use segment actions

The contextual menu offers Rewrite to Fit, Synthesize This Segment, narration preview when available, and Delete Segment. Rewrite to Fit uses the configured Gemini rewrite model to shorten the description; review its wording afterward. Synthesize This Segment generates saved speech for only that description. The Play Narration icon beside Edit previews its existing audio and is disabled when synchronized audio is unavailable.

Track changes

Origin labels distinguish AI-generated descriptions, modified AI descriptions, manually added descriptions, and older segments with unknown origin. Audio status distinguishes ready narration, narration that needs regeneration after a text edit, and missing audio. A different currently selected voice alone does not invalidate a matching saved file.

Undo Segment Edit and Redo restore AD edit history. These commands are separate from standard text undo inside the editor. Deleting generated content or clearing edit history is not the same as an ordinary reversible segment edit.
