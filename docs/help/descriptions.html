Write and edit audio descriptions

Describe useful visual information clearly and briefly. Prioritize what a listener needs to understand the story, demonstration, or on-screen instruction. Avoid repeating dialogue that already communicates the same point.

Add a segment

  1. Seek near the intended description and choose Descriptions.
  2. Choose Add Segment, or press Command-Shift-N.
  3. Set Start time and End time. The hours, minutes, seconds, and milliseconds controls support Up/Down Arrow adjustments.
  4. Enter the description. Keep it short enough to be spoken in the available time.
  5. Resolve any timing warnings, then choose Save Segment. Cancel discards the draft.

Correct text and timing

Descriptions opens in view mode. Choose Edit to show selection checkboxes and the pencil control beside every segment. Choose a pencil to edit one segment. The editor displays its duration and identifies overlaps with transcript speech or other descriptions. Save Segment is disabled for empty text, an invalid range, a range outside the video, or an overlap. End must be later than start. Change the times or text to resolve the warning.

To edit several descriptions, select their checkboxes and choose Edit Selected. Choose each selected row in the dialog, correct its text and timing, then choose Save All. Select All and Deselect All are available from Selection. Read Frame Text in the single-segment sheet can replace the draft with text detected at the start time. Review the replacement before saving. Generated descriptions and frame-text results can need corrections to names, spelling, or context.

Delete selected descriptions

In edit mode, select one or more descriptions and choose Delete Selected. The confirmation reports how many segments will be permanently removed. Confirming deletes each selected description's text and timing and also deletes its corresponding generated narration file; narration for descriptions that were not selected is kept. Cancel leaves every segment and audio file unchanged.

Use segment actions

The contextual menu offers Rewrite to Fit, Synthesize This Segment, narration preview controls, and Delete Segment. Delete Segment asks for confirmation before permanently removing the segment's text, timing, and narration. Choose Cancel to keep it unchanged. Rewrite to Fit uses the configured Gemini rewrite model to shorten the description; review its wording afterward. Synthesize This Segment generates saved speech for only that description. Each description row has Play Narration and Stop Narration controls. Play changes to Pause while its audio is playing and to Resume while paused. Stop returns the preview to the beginning. Play and Pause are disabled when synchronized audio is unavailable, while Stop is enabled only for the active or paused segment.

Track changes

Origin labels distinguish AI-generated descriptions, modified AI descriptions, manually added descriptions, and older segments with unknown origin. Audio status distinguishes ready narration, narration that needs regeneration after a text edit, and missing audio. A different currently selected voice alone does not invalidate a matching saved file.

Regenerate Audio Descriptions regenerates every Audio Description segment and its rows in AD Transcript. Immediately before generating the new descriptions, VidiStudio deletes all narration audio associated with the old segments. Existing exports remain as previously created files, but narration must be synthesized again before creating an updated described export.

Delete Segment Audio in a description's action menu asks for confirmation, then removes only that segment's generated narration and keeps its text and timing. Preview Narration becomes unavailable until audio is synthesized again. The inspector's narration trash action asks for confirmation before deleting narration for every description without deleting any segments. The same bulk action is available from Project > Narration > Delete All Narration Audio, with Command-Option-Delete.

Undo Segment Edit and Redo restore AD edit history. These commands are separate from standard text undo inside the editor. Deleting generated content or clearing edit history is not the same as an ordinary reversible segment edit.
