Welcome to VidiStudio

VidiStudio is a native Mac and Windows application for creating audio descriptions for video. Audio description (AD) tells listeners about important visual information that dialogue alone does not convey: actions, expressions, settings, and text on screen. VidiStudio combines a video player, timed transcript, editable descriptions, speech generation, and exports in a local project workflow.

Platform-specific voices. On this Mac the system choices are Apple Voices; on Windows they are Windows OneCore and Windows SAPI 5. Piper Voices are available on Mac and Windows and run offline after you download a voice. Gemini Voices, Sarvam Voices and ElevenLabs Voices each use your own key for that provider. A project moved between Mac and Windows keeps its words and timing. Saved narration keeps the voice that created it until you regenerate it on the current device. See Choose voices and play narration.

Understand the three kinds of content

Transcript
Timed words spoken in the original video. Use it to understand dialogue and locate gaps for description.
Descriptions
Your timed narration script. Generating or editing descriptions creates text, not narration audio.
Narration audio
Speech files generated from your descriptions. These files can play in time with the video and be included in exports.

How a project works

VidiStudio operates on a Bring Your Own Key (BYOK) model. You can create local video projects, import existing assets, and work with video files even without a Gemini API key configured; YouTube projects also work without one; YouTube creation requires internet, independently of Gemini. When you are ready to use automated AI features (speech transcription, video summaries, audio description drafting, and AI-powered text rewrites), enter your personal Google Gemini API key in Settings > Gemini. VidiStudio has no monthly subscriptions, intermediary servers, or user accounts: your key connects directly from your device to Google AI Studio, and it is stored securely on your device (in the macOS Keychain on Mac, and Windows Credential Manager on Windows).

Start with a video file or YouTube link, or open a video directly from your file manager. When an API key is configured, analyze the video, review the transcript and summary, then review or write description segments. Generate narration once you are happy with the words and timing. Finally, export and listen to the result from beginning to end.

If you already have a transcript, summary, AD transcript, or AD narration audio, choose I already have Audio Description files in New Project. VidiStudio can open the project immediately with Create Project & Open Editor, or build a selectable described track with Create Project & Combine. The same assets can be added later from Project > Import Existing Assets… or the editor's import button. Imported descriptions keep an Imported provenance label, and timing that overlaps dialogue or another description is flagged for retiming before described exports are allowed.

Local projects contain their media and generated results. Gemini analysis and Gemini narration require internet access and your BYOK API key. Apple on-device voices can speak descriptions without an online speech service once a project exists. Choosing Apple speech does not make Gemini video analysis available offline.

Open a YouTube video from your browser

Describe with Vidi Studio sends a YouTube video to the desktop editor. See Browser extensions for YouTube for installation and the browser commands.

Start with a short video

A short clip with clear dialogue and a few pauses is a useful first project. You can learn the workflow, check your voice settings, and hear the timing before processing a longer video. Automatically generated text is a draft: check names, facts, timing, and whether each description adds useful visual information.

System requirements

Mac: macOS 26.4 or later on Apple Silicon. Intel Mac builds are not provided. Windows x64: Windows 10 version 1809 (build 17763) or later. Windows ARM64: Windows 11 version 21H2 (build 22000) or later; the bundled x64 processing and voice helpers use Windows 11 emulation, so Windows 10 on ARM is not supported.

Release packages include the processing engine and media tools. Windows packages also include the .NET runtime and supply the Windows App SDK dependencies. Windows Help and YouTube playback require the Microsoft Edge WebView2 Evergreen Runtime; install it if it is missing on Windows 10. Windows Piper voices also require the Microsoft Visual C++ v14 x64 Redistributable, including on ARM64; it is not embedded in the current MSIX. Local media playback needs working system media components and installed voices for system narration. Online analysis, YouTube access and online voices need internet access and the appropriate accounts or API keys. Minimum-version contracts are based on the dependency/API audit; runtime testing on the oldest OS releases is still pending.

Compact desktop dialogs

Dialogs on Mac and Windows group related choices, place labels beside ordinary fields, and put related buttons on the same row when they fit. At smaller widths, fields and buttons can wrap. Multiline text, media previews and timing tables use the full width.
