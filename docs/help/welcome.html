Welcome to VidiStudio

VidiStudio is a native Mac application for creating audio descriptions for video. Audio description (AD) tells listeners about important visual information that dialogue alone does not convey: actions, expressions, settings, and text on screen. VidiStudio combines a video player, timed transcript, editable descriptions, speech generation, and exports in a local project workflow.

Understand the three kinds of content

Transcript
Timed words spoken in the original video. Use it to understand dialogue and locate gaps for description.
Descriptions
Your timed narration script. Generating or editing descriptions creates text, not narration audio.
Narration audio
Speech files generated from your descriptions. These files can play in time with the video and be included in exports.

How a project works

VidiStudio operates on a Bring Your Own Key (BYOK) model. You can create projects and work with video files even without a Gemini API key configured. When you are ready to use automated AI features (speech transcription, video summaries, audio description drafting, and AI-powered text rewrites), enter your personal Google Gemini API key in Settings > Gemini API. VidiStudio has no monthly subscriptions, intermediary servers, or user accounts: your key connects directly from your device to Google AI Studio, and it is stored securely on your device (in the macOS Keychain on Mac, and Windows Credential Manager on Windows).

Create a project from a video file or YouTube link anytime, or open videos directly into VidiStudio from your file manager (right-click and choose Describe with Vidi Studio in macOS Finder or Windows File Explorer, or use Share or Open With in macOS Finder). When an API key is configured, analyze the video, review the transcript and summary, then review or write description segments. Generate narration once you are happy with the words and timing. Finally, export and listen to the result from beginning to end.

Local projects contain their media and generated results. Gemini analysis and Gemini narration require internet access and your BYOK API key. Apple on-device voices can speak descriptions without an online speech service once a project exists. Choosing Apple speech does not make Gemini video analysis available offline.

Voices are platform-specific

Built-in offline voices follow your computer, not your project. On this Mac the system choices are Apple Voices; on Windows they are Windows OneCore and Windows SAPI 5. Both desktops also offer Piper Voices, a bundled offline neural engine with downloadable models that work for samples, saved narration, live preview, and summary read-aloud. Gemini cloud voices are available on both platforms with your API key. Azure Voices and the Windows natural-voice bridge were removed. A project moved between Mac and Windows keeps its words and timing, but its saved narration stays in the voice that created it until you regenerate it with a voice from the current computer.

Start with a short video

A short clip with clear dialogue and a few pauses is a useful first project. You can learn the workflow, check your voice settings, and hear the timing before processing a longer video. Automatically generated text is a draft: check names, facts, timing, and whether each description adds useful visual information.
