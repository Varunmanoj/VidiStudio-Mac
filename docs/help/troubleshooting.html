Solve common problems

I hear sounds instead of narration

Check that Narration is on for the project. If Play synthesized narration is selected, look at AD Overview: missing audio must be generated before it can play. For immediate speech without saved files, choose Preview segment text with Apple Speech. The two indication-sound settings explain sounds heard when narration is off or unavailable.

The voice sounds different from my selection

Saved files keep the voice that created them. Use live Apple Speech to hear current Apple settings, or explicitly regenerate audio to create files with the new selection. For System default, check Read & Speak in macOS Accessibility and the resolved label in VidiStudio. A selected app voice overrides the system default. Refresh after installing voices. Gemini saved narration uses the Gemini voice, not the Apple voice.

I cannot save a description

Enter nonempty text and check that start/end times lie inside the video, end follows start, and the range overlaps neither dialogue nor another description. Read the listed timing errors. Shorten the text if generated speech later exceeds its gap.

Descriptions or export actions are disabled

Generate transcript and summary before descriptions. Wait for processing and close editing sheets. Text export needs content of the requested type. Narration audio export needs at least one matching saved speech file. A described video export needs a local source, including for YouTube projects.

Analysis fails

VidiStudio automatically tries transient AI failures up to three times. If the action still fails, check internet access, API key, and available models in Gemini API settings, then read the final error for quota, access, or media-processing details. Correct the issue and choose Analyze Video again, or use the relevant Transcript, Summary, or Descriptions action when only that stage needs attention.

VidiStudio says it is not ready

Open Storage settings and choose Check VidiStudio. If you selected custom video tools, clear those choices to use the copies included with VidiStudio. Also make sure the project folder is available and its drive has enough free space.

A project or source is missing

Use Open Project Folder to locate the entire existing folder. Restore moved media to its project or restore a complete backup. For YouTube playback, check network access and availability of the link. Attach the matching local copy when you need local rendering.

The final export differs from preview

Confirm you generated audio after editing description text and exported again. Existing exports are snapshots. Live speech does not become export audio, and incomplete exports omit unavailable narration. Listen to the actual MP4 or M4A, or serve and play the complete Web Playback folder, including its audio balance, before sharing.
