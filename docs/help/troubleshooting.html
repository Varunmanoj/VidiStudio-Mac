Solve common problems

Working without internet

VidiStudio checks its connection at startup, when the network changes, and when you return to the app. A connection banner explains unavailable online features. Choose Check Connection to check again; unavailable services are also checked every 30 seconds while the app is active. Gemini, YouTube, and voice downloads are checked separately.

Without internet you can create local video projects, edit saved text and timing, import local assets, play saved media and narration, use installed Apple/Windows or downloaded Piper voices, and export from local files. Bundled Help and voice removal also work offline. You can open existing YouTube projects to edit them; YouTube playback, Fetch Details, project creation, metadata refresh, and fetching its soundtrack require a connection. Exports using sufficient imported local audio, including a full AD mix, and narration-only or text exports remain available.

AI generation, frame text, rewrites, automatic timing, cloud video preparation, Gemini voice generation, API-key verification, model refresh, and downloading voices or uncached samples require internet. Unavailable actions are disabled with an explanation. If an action is attempted after the connection changes, a dialog explains what is needed. Saved API-key verification and model choices are kept when a connection check fails.

If the connection disappears during an active network request, VidiStudio allows up to 30 seconds for recovery, then stops the operation and explains how to retry. Local encoding after a completed download continues. Completed results remain saved; interrupted generation is not restarted automatically. A reachable network does not guarantee that a provider will accept a request: quota, credentials, restricted videos, and service errors have separate explanations.

I hear sounds instead of narration

Check that Narration is on for the project. If Play synthesized narration is selected, look at AD Overview: missing audio must be generated before it can play. For immediate speech without saved files, choose Preview segment text with the selected voice. The two indication-sound settings explain sounds heard when narration is off or unavailable.

The voice sounds different from my selection

Saved files keep the voice that created them. Use live preview with the selected Apple or Piper voice to hear current settings, or explicitly regenerate audio to create files with the new selection. For System default, check Read & Speak in macOS Accessibility and the resolved label in VidiStudio. A selected app voice overrides the system default. Refresh after installing voices. Gemini saved narration uses the Gemini voice, and Piper saved narration uses the selected Piper model, not the Apple voice.

I cannot save a description

Enter nonempty text and check that start/end times lie inside the video, end follows start, and the range overlaps neither dialogue nor another description. A transcript must exist before a description can be authored so overlap validation can run. Read the listed timing errors. Shorten the text if generated speech later exceeds its gap.

Descriptions or export actions are disabled

Generate transcript and summary before descriptions, or import them. A summary needs a transcript, and manual description authoring needs one too. Resolve description timing before described exports; text exports remain available. Wait for processing and close editing sheets. Text export needs content of the requested type. Narration audio export needs at least one matching saved speech file. A described video export needs a local source, including for YouTube projects.

Analysis fails

VidiStudio may retry transient AI service failures up to three times. Rejected request parameters, credentials, and permissions are not retried automatically; connection failures require a manual retry. If the action still fails, check internet access, API key, and available models in Gemini API settings. Summary errors use a generic message and preserve the transcript and any existing summary. Enable Developer mode in Settings > Appearance > Advanced to include technical details in error messages; the current Gemini key is redacted. Settings > Gemini API > Advanced > Video processing offers Agentic (default) and Static for local and YouTube videos. Older Standard values are interpreted as Static automatically. Correct the issue and choose Analyze Video again, or use the relevant Transcript, Summary, or Descriptions action when only that stage needs attention.

VidiStudio says it is not ready

Open Storage settings and choose Check VidiStudio. If you selected custom video tools, clear those choices to use the copies included with VidiStudio. Also make sure the project folder is available and its drive has enough free space.

A project or source is missing

Use Open Project Folder to locate the entire existing folder. Restore moved media to its project or restore a complete backup. For YouTube playback, check network access and availability of the link. Attach the matching local copy when you need local rendering.

VidiStudio reports missing or damaged project files

Read the attention banner at the top of the editor, then choose Review Issues… (or the warning icon beside Project Information in the inspector) to open the project-named dialog with every affected file. Missing narration audio, timeline pictures, video details, or exports can be regenerated or exported again; the project deliberately stays usable. Missing project.json or the original video marks the project as Damaged because VidiStudio cannot reliably save or render it. Restore the file from the Trash or a backup, or use Delete Project to move the remaining folder to the Trash. If only the project folder is gone, use the warning’s remove action to clear the missing entry. Do not remove files from project folders manually while VidiStudio is open.

Some imported assets were omitted or flagged

Open the Import Report shown after the import. Valid rows are imported; rows that ended after the video, had invalid timing, or contained no text are omitted with a reason, and transcript rows that overlap an earlier transcript row are also omitted. Audio Description overlaps are not deleted: they are flagged for retiming. If the report says nothing was imported, the existing transcript, summary, descriptions, and audio are unchanged. Correct the file or its timing, then import again. A TXT transcript or TXT AD transcript always requires reviewed timing before it can be imported.

Description timing needs attention

This persistent banner means at least one description overlaps dialogue or another description, or lies outside the video. The affected rows show an Overlap badge, and AD Overview repeats the count. Retime those rows in Descriptions; VidiStudio never moves or deletes them automatically. Described video, described audio, narration-only audio, and audio combining stay unavailable until the count reaches zero. Text exports still work.

An imported AD transcript is not editable

If you chose Dialogue + AD combined, the file is stored as one combined caption and export track and is deliberately not split into editable description rows. To edit descriptions, import the same transcript again with AD narration only, which requires a transcript. The combined track remains available as a caption choice.

Imported narration is rejected

Narration must fit inside its description segment. Shorter audio is accepted, but audio longer than the segment is rejected with the audio duration, the available duration, and the segment range. Shorten the audio, lengthen the segment if the transcript allows it, or choose a different file. WAV, MP3, M4A, AAC, and FLAC are supported, and imported narration does not require an API key. If the segment already has audio, VidiStudio asks you to confirm the replacement after you choose the file.

Markdown formatting or images do not appear

Turn on Preview in the summary editor to see the rendered result. Headings, paragraphs, emphasis, strikethrough, lists, task lists, blockquotes, inline and fenced code, links, tables, and horizontal rules are supported. Image Markdown appears as alt text and a link; remote images are not embedded. Math, Mermaid diagrams, and footnotes are not supported. Markdown commands exist only inside the summary editor, not in a Format menu.

The final export differs from preview

Confirm you generated audio after editing description text and exported again. Existing exports are snapshots. Live speech does not become export audio, and exports using generated segment narration require current audio for every description. YouTube described exports can instead use imported AD narration or a full AD mix. Listen to the exported video or audio file, or serve and play the complete Web Playback folder, including its audio balance, before sharing.

Gemini quota, billing, or service problems pause AI

If Google reports that the key has no remaining quota or credits, rejects a request for billing or permission reasons, or the Gemini service is temporarily unavailable, VidiStudio shows a persistent warning across All Projects, every project editor, and Settings. AI reprocessing is disabled until the problem is resolved: transcript generation, summaries, Audio Descriptions, segment re-analysis, frame text, AI timing proposals, and Gemini narration cannot start. Existing transcripts, summaries, descriptions, generated narration, and exports are unchanged, and non-AI actions such as editing, importing existing assets, playback, text export, and Combine remain available. Choose Retry AI after adding billing or credits, waiting for a quota reset, or fixing permissions. A successful retry or a changed key clears the warning and re-enables AI actions. An invalid key is reported separately.

Original audio timing or source needs attention

Open Audio Sources to check the imported filename and the Playing, Export source, and Transcription source choices. If preview and export sound different, choose Use for playback and exports to hear the imported original during review too. Preferences affect future operations; existing transcripts and exports keep their recorded source.

If the audio duration differs from the video by more than 0.1 seconds, review the audio duration, video duration, and difference. Cancel keeps the current file. Choose Another File selects a replacement, and Import Anyway accepts trimming excess audio or silence after shorter audio, without stretching. Duration could not be verified also needs explicit confirmation. If the video duration later becomes known or changes, review a new mismatch through Review Audio Timing.

If the project copy is missing or changed, choose Audio File again to repair it and check timing. Unreadable audio cannot be imported through an override. If YouTube audio retrieval fails during export, use the Choose Audio File… button in the error dialog to supply a matching soundtrack. After import and duration confirmation, VidiStudio retries the same export with its format and narration choices. Cancel stops recovery without importing or retrying. Cancelling an export does not prompt for a replacement file. A full AD mix can also be used directly. Timed transcription and described exports need a known video duration, which the video preview or a metadata check can supply without AI.

You can import a local original soundtrack even if a YouTube project has no known duration while offline. VidiStudio skips the online timing lookup and asks you to review the unverified timing before choosing Import Anyway.

API key check results

In Gemini API Settings, choose Check API Key & Plan (or Check API Key & Reload Models). No API Key Entered asks you to fill the empty field. Invalid API Key means Google rejected the key. API Key Verified confirms that the entered key was accepted. API Key Check Incomplete reports a connection or service/access problem without changing the key to invalid; correct the reported problem and check again.

YouTube sign-in is not configured

If Add Account reports “YouTube sign-in has not been configured for this build,” install the latest publisher-configured VidiStudio build and try Settings > YouTube Accounts > Add Account again. Google sign-in opens in your default browser. Complete account selection and consent there, then return to VidiStudio. The publisher supplies the desktop OAuth client; your Gemini API key is configured separately in Settings > Gemini API.

Generated text uses an unexpected language

Use View Project Language near the top of the right inspector to choose Auto or a supported Gemini language for the project. Each content type has its own Saved Result picker. View Project Language switches the saved transcript, captions, summary, descriptions, timeline, and playback to that language together. Each section can keep an independent generation target; changing the viewing language preserves those targets and all saved results. A language without saved content shows an empty section. Settings > Gemini API > Default Language for New Projects sets the initial choice; existing projects start in Auto. Assign Language… changes the label of an existing result without translating its text or changing its audio.

Auto is a saved category. Auto transcription preserves all spoken languages, scripts, and language switches. Auto summaries and descriptions use the primary language detected from the original video, with English when none is identifiable. Choosing a specific language requests translated dialogue or generated prose in that language. Detected content stays in Auto until you explicitly assign another language. All Languages is a browsing filter, not a generation choice. Language availability follows the shared Gemini text-language catalog; narration voices must separately support the text.

Deleting a segment reports a timing error

Deleting a transcript or Audio Description segment leaves the source video and all remaining timestamps unchanged. Existing overlaps in other transcript rows must not block deletion. If an older app shows a general timing error when deleting, update VidiStudio and retry. For an added or edited row, check its start and end against Video Information and neighboring rows; descriptions must also fit outside transcript dialogue.

Language controls and Edit mode

Edit mode: Select the tab you want to work on, then choose Edit (or Enter Edit Mode in the Mac inspector). Language and Saved Results shows transcript controls on Transcript, summary controls on Summary, and description/narration controls on Descriptions. AD Overview shows description/narration results; AD Transcript shows its transcript and description sources. Only View Project Language is a shared project setting. View Project Language and saved-result selection are available in view mode. Changing section generation targets, using Keep All Sections in Sync, and assigning a language label require Edit mode. Save or cancel pending summary edits before changing languages or saved results. Choosing a target does not translate existing content; generate a result to create text in that language.

Language and saved-result folders

Language-specific assets are stored by language and saved result, for example audio-description/English (en)/Descriptions - Version 2 - [result ID]/ and imports/Auto/Transcript - Version 1 - [result ID]/. Auto stays its own category. Existing available assets are organized on the next project operation; assigning a language updates the location and all links without translating text or changing recordings. Files shared by alternatives use Shared Results, and files referenced across languages use Shared/Shared Results. Saved text and edit history remain in project.json; source video, original soundtrack, metadata, and thumbnails are project-wide. Cleanup checks every saved result, draft, and history entry before removing files. Interrupted moves resume from a journal. Keep the entire project folder together and do not move individual files manually.

Review Issues distinguishes missing narration for saved results from older recordings referenced only by undo/redo history. A history-only warning does not mean current playback or exports are missing audio. Restoring an older edit may require generating narration again. Moving current recordings cannot recreate missing historical recordings; restore those originals from a backup when available. The missing-file list identifies the language, saved result, and history context.
