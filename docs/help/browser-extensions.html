Browser extensions for YouTube

Describe with Vidi Studio opens a YouTube video in the installed VidiStudio desktop app so you can work on its transcript or audio description. You need an internet connection and a supported public or unlisted YouTube video.

Install for Chrome or Edge

Open the listing in the browser where you want to use the extension.

  • Describe with Vidi Studio on the Chrome Web Store. Choose Add to Chrome and confirm.
  • Describe with Vidi Studio on Microsoft Edge Add-ons. Choose Get and confirm.

Store installations update through the browser. If you previously installed an unpacked copy, turn it off or remove it in your browser’s Extensions settings so only one copy is active.

Open a YouTube video in VidiStudio

  1. On a YouTube video page, open the browser’s Extensions menu or toolbar and select Describe with Vidi Studio. In Chrome or Edge, you can also right-click a YouTube video link on any website or right-click the video page and choose Describe with Vidi Studio. The link menu uses the selected link and the page menu uses the current page.
  2. Check the video title, thumbnail, and short link in the confirmation. If YouTube cannot supply the title or thumbnail, you can still check the link. Choose Describe with Vidi Studio to continue and allow the browser to open the desktop app if prompted. Choose Cancel or press Escape to dismiss the confirmation.
  3. VidiStudio shows Opening YouTube project… while it finds or creates the project, then opens the editor. If the video already has a project, VidiStudio reopens it.

The extension accepts YouTube watch, short, Shorts, live, and embed links for a single video. A watch link may include a timestamp or playlist. For channels and other links that do not identify a single video, the extension shows “This link does not point to a YouTube video.” Choose Close or press Escape, then open the video page or use its direct link. For local files, use the desktop app’s file sharing and opening options.

Enable the bundled Safari extension

On Mac, open Safari > Settings > Extensions and turn on Describe with Vidi Studio. Allow website access if Safari prompts. The extension is included with the desktop app and updates with it. If Safari leaves an untitled tab after you cancel the app-opening prompt, press Command-W to close the tab.

Safari’s separate Share > VidiStudio command uses the macOS Share extension. See video sharing or macOS sharing after an update.
