Create your first accessible video

VidiStudio uses a Bring Your Own Key (BYOK) system for automated AI features. You can create local video projects, import existing assets, and work with video files with or without an API key; an active key connects automated transcription, video analysis, and description drafting. Choose a short local video for your first walkthrough.

  1. Optionally set up your Bring Your Own Key (BYOK). Open VidiStudio > Settings > Gemini API (Command-Comma on Mac / Ctrl-Comma on Windows). While local video project creation and existing-asset imports do not require an API key, configuring a key enables automated video analysis and description generation. Enter your Google Gemini API key from Google AI Studio, choose Check API Key & Plan (which tests the connection, automatically detects whether your account is on the Free or Paid plan, and loads compatible models), and choose your preferred models. Your key is stored securely on your device (in the macOS Keychain on Mac, and Windows Credential Manager on Windows).
  2. Create the project. In All Projects, choose New Project (Command-N on Mac / Ctrl-N on Windows). You can create local video projects with or without an API key; YouTube project creation also works without a key; when a key is configured, VidiStudio checks Gemini access before creating the folder. For a local file, select Video File, choose a video, then choose Create Project, or choose I already have Audio Description files under Audio Description to import existing assets first. You can also open any video file directly into VidiStudio from your file manager: in macOS Finder, right-click and choose Describe with Vidi Studio, choose Share > VidiStudio, or choose Open With > VidiStudio (enable Vidi Studio under System Settings > General > Login Items & Extensions > Finder Extensions if needed); in Windows File Explorer, right-click and choose Describe with Vidi Studio or Open with > Vidi Studio. For YouTube, select YouTube Video, paste the URL, choose Fetch Details, review the title and picture, and choose Create Project. The YouTube video's visibility must be Public or Unlisted; Private and every other restricted YouTube visibility setting cannot be used for Gemini video understanding. When a Gemini key is configured, VidiStudio confirms Gemini access before it creates the project folder; without a key, the project is created and AI analysis can be enabled later.
  3. Choose complete or individual processing. Use Project > Analysis > Analyze Video (Command-Option-Shift-A on Mac / Ctrl-Alt-Shift-A on Windows) to generate the transcript, summary, and Audio Descriptions in sequence. To work one step at a time, use Generate Transcript, then Generate Summary, then Generate Audio Descriptions. When a result exists, the same command becomes Regenerate. To refresh the video information and timeline pictures without AI, use Regenerate Video Details & Timeline Pictures. The icon-only Generate button immediately before Add (+) in the editor toolbar runs the action for the selected Transcript, Summary, or Descriptions section. It stays visible with the inspector open, and the inspector offers the same section action. If only certain parts need additional or improved descriptions, use Add Segment > Re-Analyze This Segment for those time ranges instead of regenerating every Audio Description.
  4. Review the script. Play the video and inspect each Audio Description. Correct misleading or unnecessary information. Add missing descriptions and adjust start/end times. Choose Save Segment when editing a segment.
  5. Choose a voice. Open Settings > Narration. Choose Apple on-device voices, Piper on-device neural voices, or Gemini TTS. Select and preview a voice.
  6. Synthesize narration. Return to AD Overview or the inspector and choose Generate All AD Audio. On Mac and Windows, the Narration Audio inspector shows Engine, Language, then Voice on Summary, Descriptions, AD Overview and AD Transcript. AD Overview also shows Language between Speech engine and Selected voice under Create narration audio, using the same selected-voice language and dialect as the inspector. Language belongs to the selected narration voice, including its dialect; Gemini voices show Multilingual. The engine and voice show the current Narration settings. If speech does not fit, shorten the text or adjust the available gap, then synthesize it again. Regenerating Audio Descriptions creates an alternative; previous descriptions and their narration stay available until you explicitly replace or delete them.
  7. Listen in context. Choose Play synthesized narration in Settings > Narration. Turn on Narration in the editor and play the video. Check that descriptions are understandable and do not obscure essential dialogue.
  8. Export. Open the Export dialog, select Video or Web Playback on the left, then choose one Audio option and one Transcript and Captions option on the right. Web Playback creates a complete HLS folder for Video.js. Choose Save. If a warning appears, follow its plain-language next step or cancel and repair missing narration first.

Bring existing assets instead

If the transcript, summary, AD transcript, or AD narration audio already exists, you do not need to run the AI stages again. In New Project, choose I already have Audio Description files under Audio Description. Select Transcript (SRT, VTT, or TXT), Summary (Markdown or TXT), AD transcript (SRT, VTT, or TXT), or AD audio (WAV, MP3, M4A, AAC, or FLAC). Timing is validated for SRT, VTT, and TXT; TXT is reviewed before importing. Choose Create Project & Open Editor to create the project, or Create Project & Combine to create selectable described video for a local source or described audio for a YouTube project. YouTube projects also accept original audio, AD narration, and full AD mixes. Original audio can be chosen whether you generate descriptions or import existing work; use Audio Sources to choose export, playback, and transcription independently. YouTube combination creates described audio rather than a local video. After creation, the same choices remain under Project > Import > Import Existing Assets… and the editor's import button. See Bring existing assets into a project for the import report and retiming rules.

Before sharing

Check the first and last description, pronunciation of names, on-screen text, transitions between dialogue and narration, and the final audio level. Live speech preview does not create files for export; generate narration before exporting.

Use View Project Language near the top of the right inspector to choose Auto or a supported Gemini language for the project. Each content type has its own Saved Result picker. View Project Language switches the saved transcript, captions, summary, descriptions, timeline, and playback to that language together. Each section can keep an independent generation target; changing the viewing language preserves those targets and all saved results. A language without saved content shows an empty section. Settings > Gemini API > Default Language for New Projects sets the initial choice; existing projects start in Auto. Assign Language… changes the label of an existing result without translating its text or changing its audio.

Auto is a saved category. Auto transcription preserves all spoken languages, scripts, and language switches. Auto summaries and descriptions use the primary language detected from the original video, with English when none is identifiable. Choosing a specific language requests translated dialogue or generated prose in that language. Detected content stays in Auto until you explicitly assign another language. All Languages is a browsing filter, not a generation choice. Language availability follows the shared Gemini text-language catalog; narration voices must separately support the text.

Choose a target language for each section

Edit mode: Select the tab you want to work on, then use its toolbar Edit/Done button or the matching command in the inspector’s Language and Saved Results controls. The inspector stays visible and switches to Done Editing while editing. On Descriptions, choose Edit > Edit Audio Description Segments, directly after Copy to…, or Edit > Done Editing Segments to finish. These controls and Project > Segments share the same editing state. Use Command-Option-E (Mac) / Ctrl-Alt-E (Windows) to toggle the active editable section. Language and Saved Results shows transcript controls on Transcript, summary controls on Summary, and description/narration controls on Descriptions. AD Overview shows description/narration results; AD Transcript shows its transcript and description sources. Only View Project Language is a shared project setting. View Project Language and saved-result selection are available in view mode. Changing section generation targets, using Keep All Sections in Sync, and assigning a language label require Edit mode. Save or cancel pending summary edits before changing languages or saved results. Choosing a target does not translate existing content; generate a result to create text in that language.

Transcript Generation Language, Summary Generation Language, and Descriptions and Narration Generation Language each have their own target-language picker in Language and Saved Results. Choose a specific language or Auto independently for each section. For example, a Hindi video can have an English transcript, a Hindi summary, and Marathi descriptions. Follow Project Language is optional for each section; those generation targets follow View Project Language for future requests, while explicit targets stay independent. Viewing always uses View Project Language across sections. Keep All Sections in Sync returns every section to Follow Project Language without deleting saved results. AD Transcript uses the chosen transcript and description results; narration stays attached to its description version.
