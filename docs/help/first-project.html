Create your first accessible video

You need a video you can use, space for a local project, and a Gemini API key if you want automated analysis. Choose a short local video for your first walkthrough.

  1. Connect analysis. Open VidiStudio > Settings > Gemini API. Enter your key, choose Load Available Models, and select the appropriate models for the available analysis tasks.
  2. Create the project. In All Projects, choose New Project. Select Video File, choose a video, then choose Create Project. VidiStudio copies it into a new project folder. Double-click the project to open its editor.
  3. Analyze. In the Project Inspector, choose Analyze Video. VidiStudio creates the transcript, summary, and description text in order. Review each result. To change only one result, open its page and choose Generate or Replace for that page. Replacing descriptions also removes narration generated for the old descriptions, so synthesize narration again afterward.
  4. Review the script. Play the video and inspect each description. Correct misleading or unnecessary information. Add missing descriptions and adjust start/end times. Choose Save Segment when editing a segment.
  5. Choose a voice. Open Settings > Narration. Choose Apple on-device voices or Gemini TTS. Select and preview a voice. For Apple speech, you can follow the macOS Read & Speak voice or select a voice override in VidiStudio.
  6. Generate audio. Return to AD Overview and choose Generate All AD Audio, or use Synthesize Narration in the inspector. If speech does not fit, shorten the text or adjust the available gap, then generate again.
  7. Listen in context. Choose Play synthesized narration in Settings > Narration. Turn on Narration in the editor and play the video. Check that descriptions are understandable and do not obscure essential dialogue.
  8. Export. Choose Video > Closed Audio Description for a described track viewers can turn on or off, or Video > Open Audio Description for narration permanently mixed into the soundtrack. If a completeness warning appears, cancel and generate or repair missing audio for a complete described version. Open the export from the inspector and listen through the finished file.

Before sharing

Check the first and last description, pronunciation of names, on-screen text, transitions between dialogue and narration, and the final audio level. Live Apple Speech preview does not create files for export; generate narration before exporting.
