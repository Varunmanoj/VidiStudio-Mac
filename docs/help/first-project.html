Create your first accessible video

VidiStudio uses a Bring Your Own Key (BYOK) system for automated AI features. You can create projects and work with video files anytime with or without an API key; an active key connects automated transcription, video analysis, and description drafting. Choose a short local video for your first walkthrough.

  1. Optionally set up your Bring Your Own Key (BYOK). Open VidiStudio > Settings > Gemini API (Command-Comma on Mac / Ctrl-Comma on Windows). While project creation does not require an API key, configuring a key enables automated video analysis and description generation. Enter your Google Gemini API key from Google AI Studio, choose Check API Key & Plan (which tests the connection, automatically detects whether your account is on the Free or Paid plan, and loads compatible models), and choose your preferred models. Your key is stored securely on your device (in the macOS Keychain on Mac, and Windows Credential Manager on Windows).
  2. Create the project. In All Projects, choose New Project (Command-N on Mac / Ctrl-N on Windows). You can create projects anytime with or without an API key. For a local file, select Video File, choose a video, then choose Create Project. You can also open any video file directly into VidiStudio from your file manager: in macOS Finder, choose Share > VidiStudio or Open With > VidiStudio; in Windows File Explorer, right-click and choose Describe with Vidi Studio or Open with > Vidi Studio. For YouTube, select YouTube Video, paste the URL, choose Fetch Details, review the title and picture, and choose Create Project. The YouTube video's visibility must be Public or Unlisted; Private and every other restricted YouTube visibility setting cannot be used for Gemini video understanding. VidiStudio confirms Gemini access before it creates the project folder.
  3. Choose complete or individual processing. Use Project > Analysis > Analyze Video (Command-Option-Shift-A on Mac / Ctrl-Alt-Shift-A on Windows) to generate the transcript, summary, and Audio Descriptions in sequence. To work one step at a time, use Generate Transcript, then Generate Summary, then Generate Audio Descriptions. When a result exists, the same command becomes Regenerate. To refresh the video information and timeline pictures without AI, use Regenerate Video Details & Timeline Pictures. The inspector shows only the action related to its current editor section. If only certain parts need additional or improved descriptions, use Add Segment > Re-Analyze This Segment for those time ranges instead of regenerating every Audio Description.
  4. Review the script. Play the video and inspect each Audio Description. Correct misleading or unnecessary information. Add missing descriptions and adjust start/end times. Choose Save Segment when editing a segment.
  5. Choose a voice. Open Settings > Narration. Choose Apple on-device voices or Gemini TTS. Select and preview a voice.
  6. Synthesize narration. Return to AD Overview and choose Generate All AD Audio, or use Synthesize Narration in the inspector. If speech does not fit, shorten the text or adjust the available gap, then synthesize it again. Regenerating Audio Descriptions deletes narration associated with the earlier descriptions.
  7. Listen in context. Choose Play synthesized narration in Settings > Narration. Turn on Narration in the editor and play the video. Check that descriptions are understandable and do not obscure essential dialogue.
  8. Export. Open the Export dialog, select Video or Web Playback on the left, then choose one Audio option and one Transcript and Captions option on the right. Web Playback creates a complete HLS folder for Video.js. Choose Save. If a warning appears, follow its plain-language next step or cancel and repair missing narration first.

Before sharing

Check the first and last description, pronunciation of names, on-screen text, transitions between dialogue and narration, and the final audio level. Live Apple Speech preview does not create files for export; generate narration before exporting.
