# VidiStudio Help Book

This documentation is intended for the bundled macOS Help Viewer. The current application source is the authority for control names, shortcuts, export formats, and persistence behavior.

## Content and verification plan

- Welcome: purpose, audio description concepts, local projects, online analysis versus offline narration.
- First project: setup, import, analysis, review, narration, export, final listening check.
- Projects: browser, list/grid, search, icon size, rename, independent windows, reopen, folders and backup.
- Editor: player, timeline, transcript, summary, descriptions, AD Overview, AD Transcript, inspector.
- Description authoring: add/edit/delete, timing, overlap, rewrite, frame text, origin and narration status, undo/redo.
- Analysis: the complete and individual workflows, page-specific generation or regeneration, non-AI metadata and thumbnail preparation, prerequisites, failure handling, and deletion.
- Narration: saved audio versus live speech, Apple and Gemini generation, voice selection, samples, fit, old-voice file preservation, indication sounds.
- Export: closed or open Audio Description video, closed- or open-caption video, M4A narration, SRT/VTT/TXT/JSON text, completeness checks, and URL-backed YouTube limits.
- Settings: Appearance, Projects, Narration, Gemini API, Developer prompts, Storage, Help; each visible control and its scope.
- Keyboard and accessibility: all application shortcuts, text-editing differences, VoiceOver, full keyboard navigation.
- Troubleshooting: disabled actions, missing audio, wrong voice, stale text, failed analysis, engine issues, missing project/source, export problems.
- Privacy and glossary: local files, external Gemini processing, credentials, portable projects, definitions.

The book will provide a topic table of contents, topic search, related links, and previous/next navigation. Apple Tips was inspected for its focused-topic presentation, Home navigation, previous/next controls, and search. Apple's Help Programming Guide is the packaging reference: https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/ProvidingUserAssitAppleHelp/authoring_help/authoring_help_book.html

Completion requires checking all topic links and anchors, the built Help bundle and index, application Info.plist registration, Help menu and Settings entry points, and rendered content in macOS Help Viewer. Screenshots are optional supporting material; text instructions must stand alone.

## Build and verify

`python3 script/build_help.py` assembles the book under `build/help/VidiStudio.help` and generates the native search index. Xcode's resource build phase performs this step automatically. The HTML files here are body fragments; shared navigation, theme, metadata, and the shortcut table are generated by that script.

`python3 script/verify_help.py path/to/VidiStudio.app` validates the actual packaged registration, every topic and anchor, internal navigation, stylesheet, and nonempty search index. The build-and-run entrypoint executes this check before signing and launching. It deliberately does not claim that a nonempty index proves native search works.

Remaining manual acceptance checks: open Help from the Help menu and from Settings; follow Home, a topic, Previous and Next; search for a distinctive word such as narration; inspect narrow and wide layouts in light and dark system appearance; navigate by keyboard and VoiceOver headings. A locked Mac prevents those checks and is not evidence of a Help Viewer failure.
