Files, privacy, and key terms

What stays on this Mac

Projects and completed outputs live in local folders. A local-video project includes a copy of its source. Apple speech generation uses installed voices. App settings live outside project folders, and your Gemini key is stored securely in the macOS Keychain rather than in a plain file. Transferring a project does not transfer your key. Protect your configuration and backups as well as the original media.

When an online service is used

Gemini tasks send the material needed for the requested analysis or speech generation to Google using your key. YouTube projects also depend on internet access. Review your organization's rules before processing private or confidential media, and review the applicable service terms and account usage. VidiStudio does not require a separate VidiStudio account.

Reusable video uploads

Videos prepared for Gemini analysis remain available for reuse for up to 48 hours, using the expiration time reported by Google. VidiStudio stores the remote video reference, source identity, and last verified availability with the project. This avoids uploading the same video for each analysis pass. The remote video expires automatically; the original local file remains in your project. Short transcription audio uploads are still deleted after use. Re-analysis sends the summary, transcript, existing descriptions, and selected draft as context.

Glossary

Audio Description (AD)
Narration added to describe important visual information that cannot be understood from the main soundtrack alone.
Closed Audio Description
A separate described audio track that viewers can turn on or off.
Open Audio Description
Audio Description permanently mixed into the program soundtrack, so every viewer hears it.
Segment
A piece of text with a start time and an end time. An Audio Description segment reserves a gap for speech.
Synthesis / TTS
Text-to-speech generation, turning words into spoken narration audio.
Synchronized audio
A saved narration file that exists and matches the segment's current text.
Transcript
Timed original dialogue.
AD Transcript
Dialogue and Audio Description text together in time order.
Regenerate
Create a new version of an existing transcript, summary, thumbnail set, or Audio Description set after confirmation where appropriate.
Export
A shareable output file or Web Playback folder created from the project's current content.

YouTube audio retrieval

Creating a YouTube audio-only or combined audio/narration export contacts YouTube to download the public video’s original audio. VidiStudio uses no browser cookies or YouTube sign-in. The audio and temporary download information stay in a temporary folder and are removed after completion, failure, or cancellation. Only the finished audio file is stored in the project. Use this export for videos you own or have permission to use.
