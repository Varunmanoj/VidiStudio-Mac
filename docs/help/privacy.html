Files, privacy, and key terms

What stays on this Mac

Projects and completed outputs live in local folders. A local-video project includes a copy of its source. Apple speech generation uses installed voices. App settings live outside project folders, and your Gemini key is stored securely in the macOS Keychain rather than in a plain file. Transferring a project does not transfer your key. Protect your configuration and backups as well as the original media.

When an online service is used

Gemini tasks send the material needed for the requested analysis or speech generation to Google using your key. Apple and Piper speech run on your device and do not send narration text to a speech service. YouTube projects also depend on internet access. Review your organization's rules before processing private or confidential media, and review the applicable service terms and account usage. VidiStudio does not require a separate VidiStudio account.

Reusable video uploads

Videos prepared for Gemini analysis remain available for reuse for up to 48 hours, using the expiration time reported by Google. VidiStudio stores the remote video reference, source identity, and last verified availability with the project. This avoids uploading the same video for each analysis pass. The remote video expires automatically; the original local file remains in your project. Short transcription audio uploads are still deleted after use. Re-analysis sends the summary, transcript, existing descriptions, and selected draft as context.

Glossary

Audio Description (AD)
Narration added to describe important visual information that cannot be understood from the main soundtrack alone.
Closed Audio Description
A separate described audio track that viewers can turn on or off.
Open Audio Description
Audio Description permanently mixed into the program soundtrack, so every viewer hears it.
Segment
A piece of text with a start time and an end time. An Audio Description segment reserves a gap for speech.
Synthesis / TTS
Text-to-speech generation, turning words into spoken narration audio.
Synchronized audio
A saved narration file that exists and matches the segment's current text.
Transcript
Timed original dialogue.
AD Transcript
Dialogue and Audio Description text together in time order.
Regenerate
Create a new version of an existing transcript, summary, thumbnail set, or Audio Description set after confirmation where appropriate.
Export
A shareable output file or Web Playback folder created from the project's current content.

YouTube audio retrieval

The first YouTube soundtrack extraction contacts YouTube to retrieve the original soundtrack. Choosing an imported original file, or using a full AD mix directly, avoids that soundtrack download. Soundtrack extraction does not use browser cookies or connected Google accounts. The first successful YouTube soundtrack extraction is saved in the project’s youtube-audio folder. Later original-audio and described-audio exports reuse that file, including after reopening or moving the whole project, changing narration or export format, or retrying a failed mix. Missing or damaged saved audio is downloaded again. Completed extractions are retained after export failure or cancellation; incomplete downloads and temporary processing files are removed. Imported audio is also copied into the project and retained with its source information. Use this export for videos you own or have permission to use.

Imported audio and online analysis

Choosing an imported original file for transcription sends the needed audio to Google using your Gemini key, including for range analysis. Temporary audio uploads are cleaned up afterward. Playing and mixing imported audio do not use Gemini. The YouTube picture and video-duration checks can still need an internet connection.

Connection checks

VidiStudio makes short, credential-free HTTPS connection checks to Google Gemini, YouTube, and Hugging Face. These checks send no API key or project content. They run at startup, after network changes, when returning to the app, and every 30 seconds while an online service is unavailable and the app is active.

Connected YouTube accounts

Optional Google sign-in retrieves your Google profile and the YouTube channels, uploads, playlists, video details and caption tracks that you authorize. Refresh tokens are stored in macOS Keychain or Windows Credential Manager, outside projects. Google access tokens are not passed to Gemini or the processing engine. Caption files and imported transcript text are stored locally when you choose an import. Sign Out removes a local connection; Disconnect Google Account revokes Google access across VidiStudio connections. Delete Stored YouTube Data in Video Details removes the selected project’s fetched information and imported YouTube caption data. Review YouTube Terms and Google Privacy Policy.

API cache lifetime

When VidiStudio starts, it expires fetched video-detail snapshots and downloaded caption source copies older than 30 days in the configured project library. Saved editable transcripts remain project content. Opening video details fetches current information. Use Delete Stored YouTube Data to remove imported YouTube transcript rows as well.

Language and saved results

Language labels, saved alternatives, narration references, source provenance, and review drafts stay in the portable local project folder. Assigning language labels, switching saved results, filtering, and deletion do not contact Gemini.

Copy to translation

Copy to with Translate Text enabled sends only the selected saved transcript, summary or description text to Gemini, using the configured text-rewrite model. Video, audio recordings, credentials and undo history are not included in the translation content. New translated versions remain local. Turning Translate Text off duplicates content locally without contacting Gemini.
